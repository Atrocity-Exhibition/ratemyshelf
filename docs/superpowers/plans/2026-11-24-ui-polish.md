# UI Polish: Hero Spacing, Mobile Collapsible Filters, Novel Details & Genre Renaming Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Clean up the homepage hero copy and eliminate the 40px gap, make catalog filters collapsible on mobile screens while remaining visible on desktop, reposition known aliases and community tags on novel detail pages with upgraded official links, and rename "themes" to "genre" across user-facing views.

**Architecture:** Update `HomeHero.tsx` and isolate `<h1 className="sr-only">` in `page.tsx` to fix home layout. Add mobile accordion state to `FilterPanel.tsx` using `lg:block` responsiveness. Integrate aliases into `NovelHeader.tsx`, restyle and move `TagVotePanel.tsx` to the bottom of the novel detail page, upgrade `ExternalLinksPanel.tsx` to "Official Links", and rename UI labels from "themes" to "genres".

**Tech Stack:** Next.js 15 (App Router), React, Tailwind CSS, Lucide icons, Vitest.

**Spec:** `docs/superpowers/specs/2026-11-24-ui-polish-design.md`

## Global Constraints

- Do not alter Prisma schemas or DB migrations (`TagCategory.THEME` remains in DB schema).
- Responsive breakpoint for sidebar is `lg` (1024px). Below `lg`, filter panel is collapsible.
- On desktop (`lg:` and up), filters must remain permanently visible without a collapse button.
- Ensure light and dark mode colors are consistent with existing design tokens (`bg-white dark:bg-[#16171c]`, `border-neutral-200 dark:border-neutral-800`).
- No external scraping or unauthorized external embeds.

## Review Focus

- Homepage spacing: `<HomeHero />` must be flush at the top with no extra 40px margin from Tailwind `space-y-10`.
- Mobile filter toggle: filter controls must be hidden when collapsed on mobile (< lg), but visible by default on desktop (>= lg).
- Alias display: novels without aliases render cleanly without empty headings or broken spacing; novels with aliases display them right below the synopsis.
- Community tag styling: form inputs and containers render cleanly in both light and dark modes with no hardcoded slate contrast issues.
- Official links: links open in a new tab with `target="_blank" rel="noreferrer noopener"` and support standard webnovel platforms.

- [ ] **Step 3: Update `NovelTagList.tsx`**

Render heading `"Genres & Tags"`, render both `novel.genres` (linking to `/novels?genres=${genre.slug}`) and `novel.tags` (linking to `/novels?tags=${tag.slug}`):

```tsx
import Link from "next/link";
import type { NovelDetailData } from "@/types/catalog";

export function NovelTagList({ novel }: { novel: NovelDetailData }) {
  const hasGenres = novel.genres && novel.genres.length > 0;
  const hasTags = novel.tags && novel.tags.length > 0;

  if (!hasGenres && !hasTags) return null;

  return (
    <section className="space-y-2">
      <h2 className="text-xs font-bold uppercase tracking-wider text-neutral-500 dark:text-neutral-400">
        Genres & Tags
      </h2>
      <div className="flex flex-wrap gap-1.5">
        {hasGenres &&
          novel.genres.map((genre) => (
            <Link
              key={genre.slug}
              href={`/novels?genres=${genre.slug}`}
              className="rounded-md border border-emerald-200 bg-emerald-50 px-2.5 py-1 text-xs font-semibold text-emerald-800 transition hover:border-emerald-400 hover:text-emerald-950 dark:border-emerald-800/80 dark:bg-emerald-950/40 dark:text-emerald-300 dark:hover:border-emerald-600 dark:hover:text-emerald-100"
            >
              {genre.name}
            </Link>
          ))}
        {hasTags &&
          novel.tags.map(({ tag }) => (
            <Link
              key={tag.slug}
              href={`/novels?tags=${tag.slug}`}
              className="rounded-md border border-neutral-200 bg-white px-2.5 py-1 text-xs font-medium text-neutral-700 shadow-xs transition hover:border-neutral-400 hover:text-neutral-900 dark:border-neutral-800 dark:bg-neutral-800/80 dark:text-neutral-300 dark:hover:border-neutral-600 dark:hover:text-white"
            >
              {tag.name}
            </Link>
          ))}
      </div>
    </section>
  );
}
```
